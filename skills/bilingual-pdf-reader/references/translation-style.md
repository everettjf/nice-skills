# 翻译规范（英 → 中）

面向「读者是中文母语者、拿这篇英文当精读材料」的场景。目标是**读得下去、经得起对照**：左边英文能逐句找到右边对应，中文本身又是一篇通顺的文章。

## 三条底线

1. **不掉信息**。原文有的句子、意思、语气，中文里都要有。宁可中文啰嗦，不可漏译、不可自行概括。
2. **不编内容**。原文没有的背景、评论、解释，不要塞进译文。需要补充说明的，放到「译注」，不要混进正文。
3. **译名一致**。人名、地名、队名、店名全篇统一；第一次出现可用「中文·原文」形式，之后只用一种。

## 逐段的对应关系

- **一段英文对一段中文**。原文一段拆成两段、或两段并成一段，读者就没法对照了。
- 原文是**对话**：每句对话仍是独立段落，中文也独立成段，不要合并成一段叙述。
- 原文是**小标题、图注、练习题**：照样给译文，不要跳过。
- 原文里的**斜体、破折号、省略号**：保留，它们往往带语气。

## 语气与口语

这里的差距最能拉开译文质量。

- **叙述部分**用干净顺畅的现代汉语：短句为主，少用「其、之、该、进行、使得」这类翻译腔词，少用「被」字句。
- **人物对话**按人物身份分开处理：
  - 受过教育的成年叙述者 / 旁白 → 标准口语；
  - 市井人物、方言、黑人英语（AAVE）等 → **给中文一个对应的口语层次**，用「甭、瞅、撂、撵、消停、稀罕、没跑、犯傻」这类词，句子短、断得多、允许重复和啰嗦。
  - **不要**把方言洗成标准书面语（人物就没了），也**不要**堆砌方言土语到读者读不懂的地步。目标是「没读过多少书，但话讲得清楚」。
- 口语里的语法错误（`They's bad men`、`There it be`）不必逐字对应，用中文的语法松散感去对应，而不是写错别字。

## 常见难点

| 原文 | 处理方式 | 例子 |
| --- | --- | --- |
| 双关、名字梗 | 优先保住梗，必要时选能让梗成立的译名 | `orange or lemon or something` 把 Lemon 译「柠檬」才能成立 |
| 夸张式威胁 / 俚语 | 直译往往比意译更有味道 | `cut a week into nine days` → 「把一个礼拜切成九天」 |
| 主被动换位造成的意味 | 中文按语序重排，保住意思 | `the blues give you up` → 「是它不要你了」 |
| 拟人化称呼 | 直接拟人，别解释 | `Mr. Pain` → 「疼先生」 |
| 时代感的老式说法 | 用「老式说法」的口吻 + 生词行注明 | `mouth fiddle` → 「口琴」 |
| 文化专有项 | 音译 + 简短说明（放生词行或译注） | `bodega` → 「街角小杂货店」 |
| 度量、货币、时间 | 保留原单位，必要时用括号补换算 | — |

## 译注（可选，但很加分）

正文之后可以加 3–8 条「译注」，只写**确实需要交代的取舍**：

- 哪一处最难译、为什么这样处理；
- 哪个词在原文里有双重意思，中文只能取一面；
- 原文的排印问题（比如引号未闭合、明显错字），以及译文的处理；
- 方言口语的翻译策略（一两句带过）。

写法要求：一条一句话，**面向读者**，不要写成给自己看的解释。原文里的错字属于「排印问题」而不是「翻译问题」，如要修正，在译注里说明，不要在正文里静默改掉却不打招呼。

## 交付前自检

- [ ] 段数与原文一一对应，没有漏段、没有合并；
- [ ] 每一段的中文都能在英文段里找到依据；
- [ ] 人名、地名、专名全篇一致；
- [ ] 数字、日期、单位没抄错；
- [ ] 大声读一遍译文，凡是读起来拗口的句子都改掉；
- [ ] 版权提示与出处写在文件开头，并提醒用户不要公开发布受版权保护的全文。
